# Kepler 0.10.3

## Fixes and compatibility

- Continue storing global data under `${XDG_CONFIG_HOME:-$HOME/.config}/vialactea-works/kepler/`. On the first global-path lookup, Kepler copies data from the previous hidden directory to the corrected path without deleting the source. Existing corrected data takes precedence, and migration from legacy `~/.hamilton/` remains supported.

## Added

- Add opt-in dependency-aware task execution. Plans can declare prerequisites while keeping task IDs and artifact paths stable. Kepler derives which tasks are ready, holds tasks whose prerequisites lack approval, and preserves full task gates before whole-change review and finish.
- Add `kepler workbench task-state` operations for guarded task admission, bounded prerequisite reservations, recovery retries, and serialized integration and verification.
- Extend workbench artifact validation and context, diff, and precondition checks for dependency execution and its history.

## Updated

- Align planning, proposal, review, orchestration, and finish workflows with task identity, approval, verification, and handoff gates.
- Keep dependency execution opt-in. Existing plans without dependency metadata retain serial numeric task order.

## Packages and release assets

The workspace contains `@vialactea-works/kepler-cli` and `@vialactea-works/kepler-core`. GitHub releases include standalone platform binaries, `kepler-bundle.tar.gz`, the versioned `kepler-core-0.10.3.tgz` tarball, and `SHA256SUMS`. The release workflow also publishes the core package to GitHub Packages.

## Installation

Install the standalone executable and sidecar bundle with the release installer:

```bash
curl -fsSL https://raw.githubusercontent.com/vialactea-works/kepler/main/install.sh | bash
npx skills add https://github.com/vialactea-works/kepler
```

The installer verifies the binary and bundle checksums, installs `kepler` on `PATH`, extracts the bundle beside it, and runs assisted setup. The second command installs the Kepler skills in your coding agent.
